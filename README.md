# Monitoreo-Ambiental-Red-Nodos-DIstribuidos-Inteligente--IoT
Sistema IoT de redes de sensores distribuidos en zonas protegidas, cada nodo  ESP32 mide condiciones ambientales y las transmite vía LoRa a un nodo central cercano al acceso de Internet. El nodo principal actúa como gateway: recibe datos de los nodos remotos y los envía a la nube, además de reenviar comandos de control a los sensores.
